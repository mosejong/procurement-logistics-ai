## ① 기술성 (20점) — "적용 기술이 적절하며 완성도가 높은가"

### 현재 강점
- **라이브 데모**: Streamlit Cloud 운영 중 (QR로 즉시 확인 가능)
- **ML 분류기 98.6%**: TF-IDF + LogReg, 홀드아웃 테스트셋 14,070건 별도 측정
- **전국 커버리지**: 253/255 시군구 = 99.2%
- **데이터 파이프라인**: 나라장터→수집→전처리→점수산정→AI해석 완전 자동화 CLI
- **AI 해석 5종**: Gemini API 연동, 수치 근거 인용형 (과해석 방지 구조)
- **IsolationForest 블루오션 탐지**: 비지도학습 이상치 탐지로 수요공백 자동 발굴

### 심사 Q&A 대비
- ML 98% 과적합 질문 → 홀드아웃 방식 + 약점(사무용품 Recall 0.57) 선제 인정
- 실시간 아니냐 → 정기 배치(월 1회) + 자동화 파이프라인 운영 중 명시
