# 공모전 발표 PPT 초안
> 2026 공공조달데이터·AI 활용 창업경진대회 / 10슬라이드

---

## Slide 1. 문제 정의

**핵심 한 문장**
> 창업자는 상권과 유동인구는 보지만, 공공기관이 무엇을 필요로 하는지는 보지 못합니다.

**본문**
- 물류 현장 10년, 입지와 수요 예측이 틀리면 재고·운영 비용이 바로 손실로 이어진다
- 예비창업자와 납품업체는 유동인구·상권 데이터는 활용하지만 공공수요 데이터는 사각지대
- 공공기관은 매년 수십만 건의 입찰공고를 발행하지만, 이 데이터는 창업 입지 분석에 쓰이지 않고 있다
- 공공수요 신호가 있는 곳에 먼저 들어가는 것이 진입 리스크를 낮출 수 있다

**발표자 포인트**
"저는 약 10년 동안 물류 현장에서 일하면서, 입지와 수요 예측이 잘못되면 재고·이동·운영 비용이 바로 손실로 이어지는 것을 직접 경험했습니다. 이 문제를 데이터로 풀 수 없을까라는 질문이 이 프로젝트의 시작입니다."

**시각자료**
- 물류창고 이미지 또는 나라장터 입찰공고 화면 캡처
- "창업자가 보는 데이터 vs 공공기관이 실제로 발행하는 데이터" 대비 도식

## Slide 2. 프로젝트 한 줄 소개

**핵심 한 문장**
> 공공조달 입찰공고를 지역별 수요 신호로 분석해, 창업 아이템·입지·물류 거점 판단을 돕는 분석 서비스입니다.

**본문**
- 나라장터 입찰공고 100,083건을 수집·분석
- 전국 17개 시/도, 220개 지역을 커버
- 공공수요 점수, 경쟁 구조, 소비층 적합도, 물류 거점 후보를 한 화면에서 탐색
- AI는 정량 지표를 사람이 읽기 쉬운 설명으로 번역하는 보조 도구로 활용

**발표자 포인트**
"나라장터 입찰공고는 공공기관이 실제로 필요로 하는 물품과 서비스를 담은 수요 신호입니다. 이 신호를 지역별로 분석하면, 어느 지역에서 어떤 품목 수요가 많은지를 파악할 수 있습니다."

**시각자료**
- 서비스 전체 흐름 다이어그램 (입찰공고 → 분석 → 지도 시각화)
- 또는 전국 지도 탭 스크린샷

## Slide 3. 서비스 대상

**핵심 한 문장**
> 공공조달 시장 진입을 고려하는 모든 사람이 대상입니다.

**본문**
- **예비창업자·소상공인**: 어느 지역에서 어떤 품목의 공공수요가 있는지 탐색
- **B2G 납품업체**: 영업 거점 우선순위 설정, 신규 지역 진입 판단
- **물류사·3PL**: 공공수요 기반 물류 거점 입지 검토
- **창업 상담기관·지자체**: 지역별 공공수요 데이터를 상담 자료로 활용

**발표자 포인트**
"이 서비스는 직접 창업하는 사람뿐만 아니라, 창업 상담사가 지역 특성을 파악하거나, 납품업체가 영업 지역을 정할 때도 활용할 수 있습니다."

**시각자료**
- 타겟별 활용 시나리오 카드 (3~4개 박스)

## Slide 4. 왜 조달청 데이터인가

**핵심 한 문장**
> 입찰공고는 공공기관이 실제로 필요로 하는 것을 공식적으로 신청한 수요 신호입니다.

**본문**
- 나라장터 입찰공고 = 공공기관이 예산을 편성해 구매 의사를 밝힌 확정 수요
- 일반 상권 분석은 소비자 트렌드 기반이지만, 공공수요는 기관 예산에 근거한 안정적 수요
- 지역마다 수요 품목 구성이 다르므로 입지별 틈새 기회 발굴 가능
- 최근 2년 데이터 기준으로 수요 추세와 발주 패턴을 파악 가능

**발표자 포인트**
"일반 상권 데이터는 소비자가 '살 것 같다'는 추정입니다. 반면 입찰공고는 공공기관이 이미 예산을 잡고 '살 것이다'라고 공식 선언한 데이터입니다. 이 차이가 중요합니다."

**시각자료**
- 일반 상권 데이터 vs 입찰공고 데이터 비교 표
- 품목군별 공고 건수 예시 차트

---

## Slide 5. 데이터 결합 구조

**핵심 한 문장**
> 4개 기관 데이터를 결합해 공공수요, 경쟁, 소비층, 생존 가능성을 하나의 점수로 연결했습니다.

**본문**
- 조달청 나라장터 → 지역·품목별 공공수요 (입찰공고 100,083건)
- 행정안전부 인구 데이터 → 지역 규모 보정 + 소비층 적합도 분석
- 소상공인시장진흥공단 상권정보 → 업종별 경쟁 포화도 (점포 밀도)
- KOSIS 통계청 생존율 데이터 → 업종별 진입 리스크 참고 지표

**발표자 포인트**
"하나의 데이터만 보면 단편적입니다. 공공수요가 있어도 경쟁이 포화됐거나, 해당 지역 소비층과 맞지 않으면 의미가 없습니다. 4개 기관 데이터를 결합해서 입체적으로 볼 수 있도록 했습니다."

**시각자료**
- 4개 기관 데이터 흐름 도식 (화살표로 연결)
- README 아키텍처 다이어그램 단순화 버전

## Slide 6. 핵심 분석 흐름

**핵심 한 문장**
> 지역을 선택하면 공공수요부터 경쟁 구조, 소비층, 물류 거점까지 한 흐름으로 분석됩니다.

**본문**
- **공공수요 점수**: 공고 건수·금액·최근성·경쟁도를 합산한 지역별 종합 매력도
- **소비층 적합도**: 품목의 주요 소비층 연령대와 지역 인구 구성 매칭
- **경쟁 구조 분석**: 인구 1만 명당 점포 수 기반 업종별 포화도
- **지역 비교**: 두 지역을 나란히 비교해 수요 포트폴리오 차이 시각화
- **물류 거점 분석**: 전국 수요 분포 기반 1·2·3티어 거점 후보 제안

**발표자 포인트**
"각 분석이 따로 노는 게 아니라 지역을 중심으로 연결되도록 설계했습니다. 전국 지도에서 지역을 선택하면 해당 지역의 모든 분석이 자동으로 연동됩니다."

**시각자료**
- 지역 분석 탭 스크린샷 (기회점수 게이지 4개 화면)
- 또는 분석 흐름 순서도

## Slide 7. 라이브 데모

**핵심 한 문장**
> 전국 지도에서 시도를 클릭하면 해당 지역의 모든 분석이 바로 열립니다.

**본문**
- 전국 지도 → 시도 클릭 → 시군구 드릴다운
- 지역 선택 → 품목별 수요 점수 + AI 해석 자동 연동
- 두 지역 나란히 비교 → 품목 구성 파이차트 + AI 비교 설명
- 물류 거점 분석 → 전국 수요 기반 거점 후보 1·2·3티어

**발표자 포인트**
"직접 보여드리겠습니다. 여기서 서울특별시를 클릭하면..."
(라이브 데모 시연 — 전국 지도 → 강남구 선택 → 지역 분석 → AI 해석)

**시각자료**
- 전국 지도 GIF 또는 스크린샷 시퀀스
  1. 전국 히트맵
  2. 시도 클릭 → 시군구 드릴다운
  3. 지역 분석 탭 결과

## Slide 8. AI 해석 역할

**핵심 한 문장**
> AI는 판단하지 않습니다. 데이터를 사람이 읽을 수 있는 언어로 번역합니다.

**본문**
- AI가 하는 일: 수치(점수, 건수, 비율)를 자연어 설명으로 변환
- AI가 하지 않는 일: 창업 성공 예측, 투자 판단, 입지 확정
- 5가지 해석 보조: 수요 설명 / 수요 공백 / 경쟁 구조 / 물류 거점 / 지역 비교
- API 오류 시에도 수치 기반 폴백 문구로 자동 대체

**발표자 포인트**
"심사위원분들이 가장 궁금해하실 부분입니다. AI가 창업을 추천한다는 게 아닙니다. 예를 들어 '이 지역 급식·식자재 공고가 42건으로 시 평균보다 2.3배 높습니다'라는 수치를, 처음 보는 분도 바로 이해할 수 있도록 설명 문장으로 바꿔주는 역할입니다."

**시각자료**
- AI 해석 전/후 비교: 왼쪽(수치 데이터) → 오른쪽(AI 설명 문장)
- 실제 AI 해석 출력 화면 캡처

## Slide 9. 비즈니스 모델

**핵심 한 문장**
> 공공조달 데이터를 창업·납품·물류 의사결정의 사전 검토 도구로 제공합니다.

**본문**
- **B2C**: 예비창업자 — 지역·품목 탐색 + AI 해석 (현재 무료 데모)
- **B2B**: 소상공인 지원센터·창업 상담기관 — 상담사용 지역 수요 리포트
- **B2B**: 납품업체 — 영업 거점 우선순위 설정 도구
- **B2B**: 물류사·3PL — 공공수요 기반 거점 입지 검토
- 단계별: POC(현재) → B2B SaaS 구독 → 플랫폼·컨설팅 연계

**발표자 포인트**
"지금은 라이브 데모를 무료로 공개한 POC 단계입니다. 실제 수익 모델은 창업 지원기관이나 소상공인 진흥공단 같은 B2B 기관에 상담 보조 도구로 제공하는 구독 방식을 생각하고 있습니다."

**시각자료**
- 타겟별 제공 가치 표 (B2C / B2B 구분)
- 또는 단계별 로드맵 (POC → SaaS → 플랫폼)

## Slide 10. 기대 효과와 한계

**핵심 한 문장**
> 감에 의존한 입지 선택을 데이터 기반 사전 검토로 바꾸는 첫 걸음입니다.

**본문**
**기대 효과**
- 공공조달 시장 진입 전 지역·품목 수요를 데이터로 사전 검토 가능
- 공공데이터 4개 기관 결합으로 다각도 분석 제공
- 창업 상담 현장에서 바로 활용 가능한 지역별 수요 리포트

**현재 한계와 보완 방향**
- 공공조달(B2G) 관점만 반영 — 민간 소비 데이터 추가 시 보완 가능
- 실사용자 피드백 미수집 — 데모 공유 후 수집 예정
- 일부 품목 데이터 부족 구간 존재 — 수집 범위 확장으로 개선 가능

**발표자 포인트**
"한계를 솔직하게 밝히는 게 오히려 신뢰를 줍니다. 이 서비스는 공공수요 관점의 사전 검토 도구이며, 창업 성공을 보장하지 않습니다. 그 점을 서비스 안에도 명시해두었습니다."

**시각자료**
- 기대 효과 3줄 + 한계 3줄 나란히
- 마지막 슬라이드답게 깔끔한 마무리 레이아웃
