## 우선순위 5개

심사위원이 도메인을 알면 무너지는 허점 2개를 막고, 1순위 동점항목(공공데이터 활용)을 깊게 파는 게 핵심

- [ ] **① 급식 시나리오 실증 보강** — aT eaT 학교급식계약 데이터 연결 (허점 방어 + 효과성)
- [ ] **② "공고=의사 / 계약=실측" 2단 구조** — 나라장터 낙찰·계약 데이터 추가 (공공데이터 활용 + 기술성)
- [ ] **③ 물류 데이터 최소 1종 연결** — 국토부 물류창고 등록정보 (제목값 회수 + 독창성)
- [ ] **④ 소개서 문서를 rubric 5축에 1:1 정렬** — 1차 심사 본체는 발표덱이 아니라 소개서
- [ ] **⑤ 경쟁 서비스 비교표 1장** — 상권정보시스템·나라장터 통계 대비 차별점 (독창성)

## 1. 기술성 (20%) — "기술이 적절하고 완성도가 높은가"

- [ ] 시스템 아키텍처 1장 추가 (데이터 수집 → 점수 산정 → AI 해석 → 시각화 파이프라인). 작동 데모가 있으니 이건 무조건 강점으로 만들 것
- [ ] 점수 모델 근거 명시: 기회점수 가중치(공고수40/금액25/최근성15/경쟁도20) 산정 이유 한 줄. 근거 없으면 임의값으로 보임.
- [ ] (권장) 단순 가중합에 ML 한 스푼: 지역 군집화(유사 수요구조), 수요공백 이상탐지, 또는 발주계획 기반 시계열 수요예측 중 하나. 
- [ ] AI 해석을 "LLM 래퍼"가 아니라 "근거 인용형"으로: 실제 공고/계약 수치를 근거로 문장 생성 + 과해석 방지 장치 명시

## 2. 공공데이터 활용 (20% + 동점 1순위) — 최고 레버리지

지금 사실상 입찰공고 1종. 조달청 데이터 안에서만 깊이를 늘리는 게 가장 효율적.

- [ ] **나라장터 낙찰정보 API** 추가 → 경쟁도를 추정에서 실측(투찰업체 수·낙찰가율)으로
- [ ] **계약정보(개방표준 서비스)** 추가 → 실제 구매 확정 신호
- [ ] **aT 학교급식계약정보** 추가 → 급식 실수요 + 공급망
- [ ] **국토부 물류창고 등록정보** 추가 → 거점 실증
- [ ] (권장) **종합쇼핑몰 품목정보**(단가계약) / **발주계획 API** → 공고 밖 수요 + 예정 수요
- [ ] 슬라이드 18 데이터 목록표를 "조달청 다종 + 타기관"으로 갱신, 각 데이터가 어느 지표에 쓰이는지 매핑

## 3. 발전 가능성 (20%) — "사업 추진 의지·성장 가능성"

현재 비즈니스 모델 슬라이드가 단계 나열에 그침. 가장 얇은 항목.

- [ ] 시장 규모 추정 1장: 창업 상담기관·소상공인지원센터 수, B2G 납품업체 규모 등 숫자로
- [ ] 수익모델 구체화: 무료 데모 → B2B 리포트/도구의 과금 단위(기관별/리포트별/구독)
- [ ] GTM(초기 진입 경로) 한 줄: 어느 상담기관·센터부터 어떻게 접촉할지
- [ ] (권장) 파일럿/검증 흔적: 상담사 인터뷰 1~2건이라도 있으면 "추진 의지" 점수에 직결

## 4. 독창성 (20%) — "기존 유사 서비스와 차별성"

- [ ] **경쟁 비교표**: 소상공인 상권정보시스템 / 나라장터 통계 / 비즈맵·오픈업 vs 본 서비스. 핵심 축은 "민간 소비 추정 vs 공공 발주 실측"
- [ ] "수요 공백(블루오션) 탐지"와 "입지+물류 거점 결합 뷰"를 차별 포인트로 명시 (지금은 말로만 있음)
- [ ] 물류 거점 정의를 "수요 집중지"에서 "창고 인프라+이동비용 고려 거점"으로 격상

## 5. 효과성 (20%) — "사회적 가치·파급 효과"

- [ ] 사회적 가치 명시: B2G 정보 비대칭 해소, 중소·소상공인 공공조달 진입장벽 완화, 지방·청년창업 활성화
- [ ] 한계 슬라이드(과해석 방지)는 유지 — 단 계약·종합쇼핑몰 데이터를 붙여 "공고만으론 수요 단정 어렵다"는 자기 한계를 스스로 메우는 구조로 연결

## 6. 제출·행정 체크 (감점/실격 방지)

- [ ] 제출물: 제품·서비스 소개서 + 참가신청서·동의서 3종(개인정보/서약/제3자 공개공유) + 예비창업자면 국세청 사실증명원
- [ ] **마감 2026.6.19(금) 18시**, 이메일(ad2424@korea.kr) 제출 — 마감 당일 말고 6.17까지 끝낼 것
- [ ] 실격 사유 확인: 동일·유사 아이디어로 당해연도 타 예선 중복 입상 / 최근 3년 유사대회 수상 상금 합 3,000만원 이상 해당 여부
- [ ] 수치 정합성 정리: 4,745 vs 220개, 449건 vs 62건, 물류 116건 등 집계 단위 정의 1장 → Q&A 즉답 준비
