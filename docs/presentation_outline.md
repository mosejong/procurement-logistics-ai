# 발표 구성안 (최신: 전국 완성판 기준)

> 작성 기준: 2026-05-17

---

## 1. 문제 제기 — "공공조달 수요는 예측 가능하다"

- 창업 실패의 핵심 원인 중 하나: 수요 판단 실패 (악성재고 = 수요-공급 불일치)
- 기존 상권분석 서비스는 민간 소비 중심 → B2G 납품·용역 창업에는 맞지 않음
- 공공조달 수요는 다르다: 기관 위치 고정, 예산 배정 완료, 반복 발주

물류창고 10년 경험에서 나온 문제의식: 수요를 잘못 읽으면 구매비용 → 보관비용 → 처리비용의 3중 손실.

---

## 2. 차별점 — "기존 서비스와 무엇이 다른가"

| 구분 | 기존 상권분석 | 이 프로젝트 |
|---|---|---|
| 수요 대상 | 민간 소비자 | 공공기관 (확정 예산 수요) |
| 타겟 | B2C 소매 | B2G 납품·용역 + 물류사 |
| 데이터 | 카드 매출, 유동인구 | 조달청 입찰공고 실 발주 기록 |
| 경쟁 분석 | 주변 점포 수 | 개방입찰 비율 + 업종 밀도 |

---

## 3. 데이터와 처리 구조

### 수집 규모
- 조달청: 전국 17개 시/도, 220개 구·시·군, **100,083건** (최근 2년)
- 행안부 연령별 인구: 242개 지역 (소비층 적합도)
- 소상공인 상권정보: 253개 지역, 10개 업종 (경쟁 포화도)
- KOSIS 신생기업 생존율: 보정 점수 산출용

### 분류 파이프라인
```
공고명 → 18개 품목군
  1단계: 키워드 규칙 매칭 (사전 정의 규칙)
  2단계: TF-IDF + Logistic Regression (98.6% 정확도, 86,991건 훈련)
  3단계: confidence < 0.55 → 기타/미분류 유지
```

### 핵심 지표
| 지표 | 계산 | 의미 |
|---|---|---|
| opportunity_score | 공고수(40%) + 금액(25%) + 최근성(15%) + 경쟁도(20%) | 지역·품목 공공수요 종합 |
| adjusted_score | opportunity_score × 생존율 × (1-소멸률) | KOSIS 보정 |
| consumer_fit_score | 주소비층 연령 비중 min-max | 소비층 인구 매칭 |
| hub_score | 물리적 공고수(50%) + 금액(30%) + 품목다양성(20%) | 물류 거점 후보 |

## 4. AI 활용 — Gemini 판정 4종

| 판정 | 트리거 | 출력 |
|---|---|---|
| ① 수요 해석 | 추천 품목 선택 | 공고수·금액·점수 기반 설명 문장 |
| ② 수요 공백 판정 | 데이터부족 품목 ≥ 3개 | 블루오션 가능성 vs 실제 저수요 근거 |
| ③ 경쟁 구조 판정 | bid_count ≥ 20인 품목 존재 | 🔴진입 비추천 / 🟡조건부 / 🟢진입 추천 |
| ④ 물류 거점 전략 | 물류 거점 분석 탭 | 권역별 1·2·3티어 거점 추천 |

모델: `gemini-3.1-flash-lite` (정식 버전)

## 5. 결과물 — 10개 탭 구성

| 탭 | 핵심 기능 |
|---|---|
| 🌏 전국 지도 | 시도 choropleth → 클릭 시 시군구 드릴다운, 기회점수·경쟁도·소비층 시각화 |
| 🔍 사업 유형 검색 | 키워드로 품목군 검색 → 관련 지역·기관 탐색 |
| 🗺️ 지역 분석 | 시/도 + 시군구 선택 → 추천 품목 바차트 + AI 수요 해석 |
| 📦 품목 분석 | 품목군 선택 → 전국 수요 지역 분포 + AI 공백·경쟁 판정 |
| ⚖️ 자치구 비교 | 두 지역 지표 나란히 비교 (타 시도 간 비교 가능) |
| 👥 소비층 적합도 | 지역·품목군별 주소비층 연령 매칭 |
| 🏪 경쟁 분석 | 업종 밀도 bar + 히트맵 + 공공수요 vs 경쟁 scatter |
| 🚚 물류 거점 분석 | hub_score 순위 + AI 권역 거점 전략 |
| 🔬 분석 근거 데이터 | 원천 데이터 필터·검색 + CSV 다운로드 |
| 📋 프로젝트 개요 | 서비스 소개, 파이프라인, 지표 설명 |

## 6. 한계와 고도화 방향

### 현재 한계
- **소비층 적합도**: 시/도별 연령 분포 추정값. 시군구 실측 미확보
- **경쟁 분석**: 소상공인 업종 밀도 = 참고 지표. 공공입찰 경쟁자 수와 직접 연결 안 됨
- **실사용자 검증**: 예비창업자·납품업체 실 피드백 미수집
- **기타/미분류 9.2%**: ML fallback 적용 후 잔존

### 발전 방향
- 시군구 연령별 인구 실측 데이터 확보 (행안부 시군구별 연령 API)
- 낙찰정보 결합 → 실제 계약 전환율 분석
- 예비창업자 인터뷰 및 사용자 테스트
- 창업지원기관 대상 B2B SaaS 전환 (구독형 서비스 모델)
