## 슬라이드 1. 프로젝트 한 줄 설명

### PPT 문구

**나라장터 전국 입찰공고로 창업 아이템·입지·물류 거점을 찾는 데이터 서비스**

- 공공조달 수요는 기관 위치 고정 + 예산 집행 주기 일정 → 예측 가능한 반복 수요 신호
- 어디서, 무엇을, 어느 거점에서 납품할지 데이터로 판단
- 예비창업자 / 납품업체 / 물류사·3PL 3개 타겟

### 발표 멘트

이 서비스는 "공공조달 입찰공고를 창업 신호로 읽는다"는 아이디어에서 출발합니다. 민간 상권 분석은 이미 여러 서비스가 있지만, 공공기관이 어디서 무엇을 얼마나 사는지를 지역별 수요 지도로 만든 서비스는 없습니다. 여기에 AI 판정과 물류 거점 분석을 더해, 창업자부터 납품업체, 물류사까지 활용할 수 있는 도구로 만들었습니다.

## 슬라이드 2. 문제의식과 차별점

### PPT 문구

**기존 상권분석과 무엇이 다른가**

| 구분 | 기존 상권분석 서비스 | 이 프로젝트 |
|---|---|---|
| 수요 대상 | 민간 소비자 | **공공기관** (예산 집행 확정 수요) |
| 데이터 출처 | 카드 매출, 유동인구 | **조달청 입찰공고** (실제 발주 기록) |
| 타겟 | B2C 소매 창업 | **B2G 납품·용역 창업 + 물류사** |
| 경쟁 분석 | 주변 업종 점포 수 | **개방입찰 비율 + 소상공인 업종 밀도** |

물류창고 10년 현장 경험 → 악성재고는 수요 판단 실패의 결과. 공공조달 수요는 예측 가능하고 반복된다.

### 발표 멘트

저는 물류창고에서 10년간 일하면서, 악성재고가 단순히 남은 물건이 아니라 수요와 공급이 어긋난 결과라는 점을 체감했습니다. 공공조달 수요는 기관 위치가 고정되고 예산이 배정되어 있어, 민간 소비보다 훨씬 예측 가능합니다. 기존 상권분석이 민간 소비자를 대상으로 한다면, 이 서비스는 공공기관 수요를 타겟으로 합니다.

## 슬라이드 3. 데이터와 분석 구조

### PPT 문구

**4개 기관 데이터 + ML 분류기 + AI 판정 4종**

```
조달청 입찰공고 API        → 100,083건, 전국 17개 시/도
행안부 연령별 인구 통계     → 소비층 적합도 (242개 지역)
소상공인 상권정보 API       → 업종 경쟁 포화도 (253개 지역, 10개 업종)
KOSIS 신생기업 생존율 API   → 보정 점수 (생존율 × 소멸률 반영)
```

ML 분류기: 공고명 → 18개 품목군
- 1단계: 키워드 규칙 매칭
- 2단계: TF-IDF + Logistic Regression (정확도 98.6%, 86,991건 훈련)
- 3단계: confidence 미달 → 기타/미분류 유지

AI 판정 4종 (Gemini):
- ① 추천 품목 공공수요 해석 문장
- ② 수요 공백: 블루오션 vs 실제 저수요 판정
- ③ 고수요 구간: 🔴진입 비추천 / 🟡조건부 / 🟢진입 추천
- ④ 물류 거점 전략: 1·2·3티어 권역 추천

### 발표 멘트

데이터는 조달청(필수), 행안부, 소상공인시장진흥공단, KOSIS 4개 기관을 실결합했습니다. 공고명은 키워드 규칙과 ML 분류기 2단계를 거쳐 18개 품목군으로 분류합니다. 여기에 Gemini가 수요 해석, 공백 판정, 경쟁 구조 분석, 물류 거점 전략 4가지를 자동으로 생성합니다.

## 슬라이드 5. 한계와 발전 방향

### PPT 문구

**현재 한계 (솔직한 평가)**

| 항목 | 내용 |
|---|---|
| 소비층 적합도 | 시/도별 연령 분포 기반 추정 — 시군구 실측 데이터 아님 |
| 경쟁 분석 | 소상공인 점포 밀도 = 참고 지표. 입찰 경쟁자 수와 직접 연결 안 됨 |
| 실사용자 검증 | 예비창업자 실제 피드백 미수집 |
| 기타/미분류 | ML 적용 후 9.2% 잔존 |

**발전 방향**

- 시군구 연령별 인구 데이터 실측 확보 → 소비층 적합도 정확도 향상
- 낙찰정보 결합 → 실제 계약 성사 여부까지 분석
- 예비창업자 인터뷰 및 사용자 테스트 → 효과성 검증
- B2B SaaS 전환: 창업지원기관·납품업체 구독형 서비스

### 발표 멘트

현재 가장 큰 한계는 소비층 적합도가 시군구 실측 데이터가 아니라 시/도 추정값이라는 점입니다. 또한 실제 예비창업자가 써봤다는 검증 데이터가 없습니다. 다음 단계에서는 실측 데이터 확보와 함께, 창업지원기관 대상 B2B 서비스로 전환하는 것이 현실적인 발전 방향이라고 생각합니다.
