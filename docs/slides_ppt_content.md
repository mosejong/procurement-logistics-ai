## 슬라이드 C — 서비스 독창성 (독창성 축)

**위치: p06 "왜 조달청 데이터인가" 하단에 박스 3개 추가** (페이지 신설 아님, 기존 슬라이드 병합)
**제목:** 3가지 차별점 — 기존 서비스가 하지 않는 것

### 차별점 ① 공공 발주 실측 기반
```
기존 서비스          →     본 서비스
민간 소비 추정           공공 발주 확정 수요
(상권분석, 유동인구)      입찰공고 = 의사 / 계약 = 실측
"아마 팔릴 것 같은"      "실제로 구매할 기관이 있음"
```
> 공공조달은 예산·기관이 고정 = 반복 가능한 예측 수요

### 차별점 ② 지역 × 품목 × 물류 인프라 3축 결합
```
경쟁 서비스     입찰공고만 집계 → "어디서 많이 삼"
본 서비스       입찰(수요) + 계약(확정) + 창고(인프라) → "어디서, 무엇을, 어떻게 납품"
```
> 수요가 있어도 납품 거점이 없으면 사업 불가 — 인프라 가시화

### 차별점 ③ AI 해석 + 과해석 방지 구조
```
일반 AI         항상 긍정적, 검증 없는 추천
본 서비스       기본값 🔴 진입 주의 → 수치 근거 조건 충족 시만 🟢 허용
                창업 성공 예측 금지, 수치 출처 인용 강제
```
> "전라도 시골에 IT회사" 수준의 현실적 판단 = 신뢰할 수 있는 분석

## 슬라이드 D — 사회적 가치 (효과성 축)

**위치: p17 "기대 효과와 한계" 슬라이드에 병합** (페이지 신설 아님)
**제목:** 정보 비대칭 해소 → 공공조달 진입장벽 낮추기

### 사회적 가치 ①  B2G 정보 비대칭 해소
- **문제:** 공공조달 데이터는 공개되어 있지만 해석·접근 기술이 없어 대기업·기존 납품사 독점
- **효과:** API → 분석 → 시각화 전 과정 자동화로 비전문가도 지역별 수요 파악 가능
- **수치:** 나라장터 공고 100,083건, 17개 시/도, 220개 지역 — 모두 공개 API 기반

### 사회적 가치 ②  중소·소상공인 공공조달 진입장벽 완화
- **문제:** 조달 시장 참여 기업 634,291개 중 대부분이 지역별 수요 패턴을 모르고 진입
- **효과:** 품목별 수요공백(블루오션) 자동 탐지 → 경쟁 적은 틈새 시장 발굴 지원
- **수치:** 블루오션 탐지 top-50 자동 추출, competition_score 기반 진입 용이 지역 필터링

### 사회적 가치 ③  지방·청년 창업 활성화
- **문제:** 창업 상담 시 지방 수요 데이터 부재 → 수도권 쏠림, 지방 기회 미발굴
- **효과:** 전국 220개 지역 공공수요 가시화 → 지방 유망 품목·지역 데이터 근거 제시
- **수치:** 창업 상담기관 약 200개소(창진원 기준), 예비창업자 연간 10~15만명 대상

### 파급 효과 요약
| 대상 | 현재 문제 | 서비스 효과 |
|---|---|---|
| 예비창업자 | 감에 의존한 창업 아이템 선정 | 데이터 근거 사전 검토 |
| 소규모 납품업체 | 어느 지역에 집중할지 불명확 | 품목×지역 수요 밀도 지도 |
| 창업 상담기관 | 지역별 공공수요 데이터 없음 | B2B 분석 도구로 상담 효율화 |

## 슬라이드 E — 데모 6 (공공수요 예측 트렌드 탭)

**위치: 기존 AI 해석 데모 슬라이드 자리에 교체** — 신규 페이지 없음, 20페이지 유지  
**제목:** 📊 공공수요 예측 — 향후 3개월 트렌드 + 블루오션 자동 판정

### 스크린샷 추천 설정

| 항목 | 값 |
|---|---|
| 시/도 | 전국 (전체) |
| 품목군 | 급식/식자재 |
| 기대 결과 | 📈 증가 트렌드, 🟢 블루오션 또는 🟡 평범 판정, 예측 구간(빨간 점선) 표시 |

> 급식/식자재를 선택하면 aT 연계 맥락과 자연스럽게 이어집니다 (데모 3 해운대구 스크린샷 이후 흐름).  
> 증가 트렌드가 나오지 않으면 **시설관리/공사** 또는 **IT/소프트웨어**로 대체.

### 슬라이드 본문 구성 (2단 레이아웃)

**[좌측 — 수요공백 판정 카드]**
```
┌───────────────────────────────────────────────┐
│  수요공백 판정        공공수요 점수   공고 수   │
│  🟢 블루오션          28.4점         183건     │
│                                               │
│  대표: 부산 해운대구 (183건) · 이상탐지 0.812  │
│  수요 대비 경쟁이 낮은 진입 기회 지역           │
└───────────────────────────────────────────────┘
```

**[우측 — 트렌드 + 예측 차트]**
```
  건수
  250 │  ▐▌  ▐▌              ← 실제 공고 (막대)
  200 │  ▐▌  ▐▌ ▐▌
  150 │──────────────◆  ◆  ◆  ← 예측 (3개월, 빨간 점선)
  100 │          ~~~~          ← 3개월 이동평균 (노란선)
      └──────────────────────→
      2024.01          2025.06  예측 →
      [           ]  ← 예측 구간 음영 (연빨강)
```

**하단 캡션 (슬라이드에 넣을 문구):**
> 선형 추세 모델 — 계절성·외부 요인 미반영. 트렌드 방향 참고용 (정밀 예측 아님).

### 핵심 메시지 (발표 포인트 3개)

1. **과거→미래 전환**: 경쟁 서비스는 "얼마나 발주됐는가(과거)" 만 보여줌 → 본 서비스는 "앞으로 3개월 얼마나 발주될 것인가(미래)" 예측 제공
2. **블루오션 자동 판정**: 수요 이상탐지 알고리즘으로 전국 50개 수요공백 지역 자동 추출 → 🟢/🟡/🔴 3단계 판정으로 진입 여부 즉시 판단
3. **계절성 경보**: 특정 품목(예: 시설공사, 방역)의 발주 집중 시기를 자동 감지해 경고 — 타이밍 전략까지 제시

### 차별점 비교 박스 (슬라이드 하단에 삽입 권장)

```
기존 서비스    ← 과거 집계만 제공 ("지난해 이 지역 발주 N건")
본 서비스      ← 예측 + 판정 자동화
               ① 향후 3개월 수요 방향 예측 (선형 트렌드)
               ② 수요공백 이상탐지 → 블루오션 50곳 자동 선별
               ③ 계절성 경보 — "이 품목은 상반기에 몰림, 지금 준비해야"
```
