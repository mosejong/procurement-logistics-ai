## 슬라이드 1 — 시장 배경과 대상 사용자

**제목:** 공공조달 수요를 창업 입지·품목 판단 근거로 전환

**핵심 메시지:**
공공조달 시장은 크고, 참여 기관과 조달기업도 많지만 예비창업자나 소규모 납품업체가 지역별·품목별 수요를 해석하기는 어렵다. 본 서비스는 공공 발주 데이터를 창업 전 사전 검토 자료로 바꿔주는 분석 도구로 확장할 수 있다.

---

### 시장 배경
- 2024년 공공조달 규모: **225.1조원** (전년 대비 7.9% 증가, 조달청 발표)
- 2025년 나라장터 수요기관 등록 수: **74,892개**
- 2025년 나라장터 조달기업 등록 수: **634,291개**
  - 이 중 중소기업: **613,291개**

### 초기 타겟 사용자

| 사용자 | 활용 상황 |
|---|---|
| 예비창업자 | 창업 전 후보 지역·품목 사전 검토 |
| 창업상담기관 / 소상공인지원센터 | 상담 시 데이터 기반 근거 제공 |
| B2G 납품 희망 소상공인·중소 유통업체 | 공공수요 반복 지역·품목 탐색 |
| 지자체 창업지원 부서 | 지역별 공공수요 현황 파악 |

### 확장 타겟 (2차·제휴)

| 사용자 | 보완 관계 |
|---|---|
| 비즈맵·오픈업 등 상권분석 플랫폼 | 민간 소비 데이터 보유 + 공공 발주 수요 신호 부재 → API/모듈 제공 |
| 지자체 데이터 플랫폼 | 지역 공공수요 가시화 리포트 납품 |
| 창업 컨설팅 플랫폼 | 공공수요 분석 모듈 임베드 |

---

> ※ 위 수치는 서비스 매출 규모가 아니라,
> 공공조달 수요 기반 분석 도구의 적용 가능성을 보여주는 **시장 배경 지표**입니다.

## 슬라이드 2 — 수익모델 · GTM · 확장 로드맵

**제목:** 무료 데모에서 기관용 리포트 · 구독형 분석 도구로 확장

**핵심 메시지:**
현재는 급식·식자재 카테고리에서 데이터 결합 구조를 검증한 MVP이며, 향후 카테고리별 보조 데이터를 확장해 기관용 분석 리포트와 창업 상담 도구로 발전시킬 수 있다.

---

### 수익모델 벤치마크

> 기존 상권분석 플랫폼과 경쟁하기보다, 공공 발주 수요 데이터를 보완 레이어로 제공

기존 상권분석 서비스(비즈맵 등)는 민간 소비·매출·유동인구 기반 리포트를 1건 단위 과금으로 제공합니다.
본 서비스는 이들이 보유하지 않은 **공공 발주·계약 실측·물류 인프라 데이터**를 보완하는 B2G 수요 분석 모듈로 확장할 수 있습니다.

> 비즈맵 프리미엄 보고서: **55,000원/건** (민간 소비·매출·유동인구 중심, B2C 상권)
> 본 서비스 확장 방향: 공공 발주 수요 기반 B2G 리포트/API 모듈 제공

**PPT 삽입용 한 줄:**
```
기존 상권분석 리포트: 민간 소비·매출 중심, 1건 단위 과금 모델 존재
본 서비스 확장 방향: 공공 발주 수요 기반 B2G 리포트/API 모듈 제공
```

### 수익모델
| 단계 | 형태 | 과금 단위 |
|---|---|---|
| 현재 | 무료 Streamlit 데모 (POC 검증) | — |
| 단기 | 지역·품목별 공공수요 분석 리포트 | 리포트 건당 또는 기관 구독 |
| 중기 | 창업상담기관용 대시보드 구독 | 기관별 월정액 |
| 중기 | B2G 납품 희망업체 대상 카테고리별 수요 리포트 | 리포트 건당 |
| 장기 | 상권분석 플랫폼 대상 공공수요 데이터 API/모듈 제공 | API 호출 건수 또는 라이선스 |

### GTM (초기 진입 경로)

**1단계:** Streamlit 무료 데모 공개 및 피드백 수집
- 실제 화면과 QR로 아이디어의 실현 가능성 검증

**2단계:** 창업상담기관·소상공인지원센터 대상 파일럿 제안
- 전국 소상공인지원센터는 지역별 상담 접점 역할 (소상공인시장진흥공단 운영)

**3단계:** 급식·식자재 납품/유통업체 대상 지역 수요 리포트 제공
- aT 공공급식 전자조달(eAT)은 급식용 식재료 구매·계약 시스템
- 본 프로젝트에서 BID 285,552건, AWARD 448,690건 수집 → 지역별 수요 분석 가능성 확인

**4단계:** 민간 상권분석 플랫폼이 보유하지 않은 공공 발주·계약 수요 데이터를 API 또는 리포트 모듈 형태로 제공
- 기존 상권분석 플랫폼(비즈맵·오픈업 등): 민간 소비·매출 강점, 공공 발주 수요 신호 없음
- 보완 관계 → "비즈맵이랑 싸운다"가 아니라 "비즈맵에 없는 레이어를 우리가 제공"
- 나라장터 수요기관 74,892개, 조달기업 634,291개 규모 생태계
- 소상공인 기업체 613.4만개, 종사자 961.0만명 (중기부 2024년 소상공인실태조사)

### 확장 로드맵
```
1단계  → 급식·식자재 카테고리 MVP 검증 (현재)
2단계  → 창업상담기관·소상공인지원센터 대상 파일럿 (초기 B2B)
3단계  → 급수·전기·설비 / 청소·방역 / 교육물품 카테고리 확장
4단계  → 상권분석 플랫폼 대상 공공수요 데이터 API/모듈 제공 (제휴·확장)
```

---

> ※ 현재 단계는 수익화 완료가 아니라,
> **급식·식자재 카테고리에서 데이터 기반 의사결정 구조를 검증한 MVP**입니다.

## 발표 멘트 — 30초 버전

```
발전 가능성은 단계적 확장 구조로 잡았습니다.
현재는 급식·식자재 카테고리에서 데이터 결합 구조를 검증한 MVP입니다.
다음 단계에서는 창업상담기관과 소상공인지원센터를 초기 B2B 타겟으로 파일럿 제안하고,
품목 카테고리를 급수·설비, 청소·방역, 교육물품으로 넓힙니다.
비즈맵이나 오픈업 같은 기존 상권분석 서비스는 민간 소비와 매출 추정에 강점이 있습니다.
반대로 저희 서비스는 공공기관 발주 수요와 계약 데이터를 기반으로 하기 때문에,
향후에는 기존 상권분석 플랫폼에 B2G 수요 데이터 모듈로 연계할 수 있습니다.
```

## 절대 쓰면 안 되는 표현

```
❌ 225조 시장을 타깃으로 한다
❌ 전국 창업상담기관에 바로 판매 가능
❌ 창업 성공률을 높인다
❌ 모든 업종에 적용 완료
```

## 써야 하는 표현

```
✅ 공공조달 시장을 배경으로 한 분석 도구
✅ 초기 대상은 창업상담기관·B2G 납품 희망업체
✅ 현재는 급식·식자재 카테고리 검증형 MVP
✅ 향후 카테고리별 보조 데이터로 확장
✅ 상권분석 플랫폼 대상 공공수요 API/모듈 연계 (확장 타겟, 4단계)
```

```
✅ 민간 상권분석 플랫폼이 보유하지 않은 공공 발주·계약 수요 데이터를 보완 레이어로 제공
✅ 경쟁이 아니라 보완 — "비즈맵에 없는 공공수요 레이어를 우리가 제공"
```
