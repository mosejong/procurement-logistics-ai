## 슬라이드 1 — 시장 배경과 대상 사용자

**제목:** 공공조달 수요를 창업 입지·품목 판단 근거로 전환

**핵심 메시지:**
공공조달 시장은 크고, 참여 기관과 조달기업도 많지만 예비창업자나 소규모 납품업체가 지역별·품목별 수요를 해석하기는 어렵다. 본 서비스는 공공 발주 데이터를 창업 전 사전 검토 자료로 바꿔주는 분석 도구로 확장할 수 있다.

---

### 시장 배경
- 2024년 공공조달 규모: **225.1조원** (전년 대비 7.9% 증가, 조달청 발표)
- 2025년 나라장터 수요기관 등록 수: **74,892개**
- 2025년 나라장터 조달기업 등록 수: **634,291개**
  - 이 중 중소기업: **613,291개**

### 대상 사용자

| 사용자 | 활용 상황 |
|---|---|
| 예비창업자 | 창업 전 후보 지역·품목 사전 검토 |
| 창업상담기관 / 소상공인지원센터 | 상담 시 데이터 기반 근거 제공 |
| B2G 납품 희망 소상공인·중소 유통업체 | 공공수요 반복 지역·품목 탐색 |
| 지자체 창업지원 부서 | 지역별 공공수요 현황 파악 |

### 활용 상황
- 창업 전 후보 지역·품목 사전 검토
- 공공기관 수요가 반복되는 지역 확인
- 상담사가 창업자에게 데이터 기반 근거 제공
- B2G 납품 가능성이 있는 품목·지역 탐색

---

> ※ 위 수치는 서비스 매출 규모가 아니라,
> 공공조달 수요 기반 분석 도구의 적용 가능성을 보여주는 **시장 배경 지표**입니다.

---

## 슬라이드 2 — 수익모델 · GTM · 확장 로드맵

**제목:** 무료 데모에서 기관용 리포트 · 구독형 분석 도구로 확장

**핵심 메시지:**
현재는 급식·식자재 카테고리에서 데이터 결합 구조를 검증한 MVP이며, 향후 카테고리별 보조 데이터를 확장해 기관용 분석 리포트와 창업 상담 도구로 발전시킬 수 있다.

---

### 수익모델
| 단계 | 형태 | 과금 단위 |
|---|---|---|
| 현재 | 무료 Streamlit 데모 | — |
| 단기 | 지역·품목별 공공수요 분석 리포트 | 리포트 건당 또는 기관 구독 |
| 중기 | 창업상담기관용 대시보드 구독 | 기관별 월정액 |
| 장기 | 지자체·센터 맞춤형 공공수요 분석 + B2G 납품업체 카테고리별 수요 리포트 | 프로젝트 단위 |

### GTM (초기 진입 경로)
1. Streamlit 무료 데모 공개 및 피드백 수집
2. 창업상담기관·소상공인지원센터 대상 파일럿 제안
3. 급식·식자재 납품/유통업체 대상 지역 수요 리포트 제공
4. 지자체 창업지원 부서와 협업형 분석 리포트 확장

### 확장 로드맵
```
현재  → 급식·식자재 카테고리 MVP 검증
다음  → 급수·전기·설비 / 청소·방역 / 교육물품 카테고리 확장
이후  → B2G 공공수요 + B2C 상권·인구·계절성 데이터 결합
```

---

> ※ 현재 단계는 수익화 완료가 아니라,
> **급식·식자재 카테고리에서 데이터 기반 의사결정 구조를 검증한 MVP**입니다.

---

## 발표 멘트 — 30초 버전

```
발전 가능성은 두 방향으로 잡았습니다.
첫째, 공공조달 시장은 2024년 기준 225.1조원 규모이고, 나라장터에 등록된
수요기관과 조달기업도 많기 때문에 공공수요를 해석하는 도구의 활용 여지가 있습니다.
둘째, 현재는 급식·식자재 카테고리 MVP로 검증했지만,
향후 급수·설비, 청소·방역, 교육물품 등 카테고리별 보조 데이터를 붙이고,
창업상담기관이나 소상공인지원센터용 리포트·대시보드로 확장할 수 있습니다.
```

---

## 절대 쓰면 안 되는 표현

```
❌ 225조 시장을 타깃으로 한다
❌ 전국 창업상담기관에 바로 판매 가능
❌ 창업 성공률을 높인다
❌ 모든 업종에 적용 완료
```

## 써야 하는 표현

```
✅ 공공조달 시장을 배경으로 한 분석 도구
✅ 초기 대상은 창업상담기관·B2G 납품 희망업체
✅ 현재는 급식·식자재 카테고리 검증형 MVP
✅ 향후 카테고리별 보조 데이터로 확장
```
