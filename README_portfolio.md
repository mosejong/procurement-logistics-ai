# 공공조달 수요 기반 사업 아이템·입지·물류 거점 분석 서비스

> 잘못된 수요 판단은 구매비용, 보관비용, 처리비용으로 이어지는 3중 손실을 만듭니다.

공공조달 입찰공고를 지역별 공공수요 신호로 해석해,  
예비창업자·납품업체·물류사가 수요 패턴을 데이터 근거로 파악할 수 있는 분석 서비스입니다.

단순히 "많이 발주된 품목"을 보여주는 것이 아니라,  
**수요 공백이 블루오션인지 실제 저수요인지**, **고수요 지역이 레드오션인지 진입 여지가 있는지**,  
그리고 **어디에 물류 거점을 잡아야 공공수요를 효율적으로 커버할 수 있는지**까지 AI가 판정합니다.

## 왜 이 프로젝트인가

물류창고 현장에서 10년간 재고 불균형과 악성재고 문제를 다뤘습니다.  
악성재고는 한 번 잘못 매입하면 구매비용, 보관비용, 처리비용으로 세 번 손실을 만듭니다.

창업도, 납품 거점 선택도 다르지 않습니다.  
수요가 없는 지역, 맞지 않는 품목으로 시작하면 같은 구조의 손실이 반복됩니다.

공공조달 데이터는 기관 위치가 고정되고 예산 집행 주기가 일정한 **예측 가능한 반복 수요**입니다.  
이 데이터를 지역별 수요 패턴으로 해석하면, 잘못된 수요 판단으로 생기는 손실을 줄이는 출발점이 될 수 있습니다.

이 프로젝트는 그 지점에서 출발했고,  
전국 데이터를 수집하면서 단순 창업 추천을 넘어 **물류 거점 설계**로 확장됐습니다.

## 이 서비스가 하는 것

- 조달청 나라장터 입찰공고를 전국 17개 시/도, 220개 지역 단위로 수집합니다.
- 기관명 → `agency_type`, 공고명 → `item_category_detail` 두 가지 분류를 생성합니다.
- 공고수·금액·최근성·경쟁도를 결합한 `opportunity_score`를 산출합니다.
- 인구 1만명당 공고수(`bids_per_10k_population`)로 지역 규모 편향을 보정합니다.
- 규제 업종과 데이터 부족 카테고리를 추천에서 자동 분리합니다.
- **AI 판정 ①** 데이터부족 품목에 대해 블루오션인지 실제 저수요인지 인근 지역 데이터와 비교해 판정합니다.
- **AI 판정 ②** 고수요 품목에 대해 레드오션인지 진입 여지가 있는지 경쟁 구조를 분석합니다.
- **AI 판정 ③** 물리적 납품 품목의 시/도별 수요 밀도를 분석해 최적 물류 거점 구조를 제안합니다.
- 추천 항목에 한해 Gemini 기반 공공수요 해석 문장을 생성합니다.

## 이 서비스가 하지 않는 것

- 창업 성공 여부를 예측하지 않습니다.
- 민간 소비수요(상권, 소비자 데이터)를 직접 반영하지 않습니다.
- `opportunity_score`는 공공수요 참고 지표이며, 창업 성공 예측값이 아닙니다.
- AI 설명 문장은 데이터 해석이며, 투자·창업 판단 근거가 아닙니다.

## AI 활용 구조

이 프로젝트는 AI를 세 가지 역할로 활용합니다.

| 역할 | 기능 | 입력 | 출력 |
|---|---|---|---|
| 수요 설명 | 추천 품목의 발주 패턴 설명 | 공고수·금액·최근성·경쟁도 수치 | 수요 특성 해석 문장 |
| 수요 공백 판정 | 데이터부족이 블루오션인지 저수요인지 판정 | 인근 지역 동일 품목 공고 수 비교 | 판정 결과 + 접근 방법 |
| 경쟁 구조 판정 | 고수요 지역의 진입 가능성 판단 | 개방경쟁 비율, 공고 수, 집행 속도 | 🔴진입 비추천 / 🟡조건부 / 🟢진입 추천 |
| 물류 거점 전략 | 전국 수요 분포 기반 최적 허브 구조 제안 | 시/도별 물리적 납품 공고 수·금액 | 1·2·3티어 거점 전략 |

**AI는 추천을 임의 생성하지 않습니다.**  
모든 AI 판정은 정량화된 수치를 프롬프트로 전달받아 데이터 해석과 판단 근거 제시에만 사용됩니다.  
API 오류 시 수치 기반 폴백 문장으로 자동 대체되며 앱은 정상 작동합니다.

## 데이터 파이프라인

```text
조달청 입찰공고 API
  → 전국 시/도 단위 bulk 수집 (build_national_sample.py)
  → 기관명/공고명 분류 (classify_agency.py)
      기관명 → agency_type (8개 유형)
      공고명 → item_category (19종, bid_cleaned_national.csv 기준)
        → 매트릭스·수요예측·블루오션 전 단계에서 동일 카테고리 사용
      (ML 분류기: agency_type 8종 분류에서 계속 사용 — TF-IDF + LogReg, 정확도 98.6%)
  → 자치구·시·군 × 품목군 매트릭스 생성 (build_opportunity_matrix.py)
  → opportunity_score 산출 (공고수 40% + 금액 25% + 최근성 15% + 경쟁도 20%)
  → 추천 정책 적용 (recommendation_flag: 추천 / 제외 / 데이터부족)
  → 인구 보정 피처 추가 (build_features.py)
      전국 시·군·구 인구 데이터 결합 → bids_per_10k_population
  → Gemini AI 판정 (gemini_client.py)
      컨텍스트 자동 주입: 발주계획 건수·금액 + MAS 등록 품목수·평균단가
      ① 수요 설명: 추천 항목 공공수요 해석
      ② 데이터부족 판정: 블루오션 vs 실제 저수요
      ③ 과수요 판정: 레드오션 vs 진입 여지
      ④ 물류 거점 전략: 1·2·3티어 허브 구조 제안
  → Streamlit 대시보드 (streamlit_review.py)

조달청 발주계획 API + 종합쇼핑몰 MAS API
  → collect_plan_data.py
      발주계획: 향후 6개월 445건 (1,249.8억원) → 시/도×품목군 집계
      MAS 품목: 다수공급자계약 5,000건 → 품목군별 등록현황 집계
      → procurement_plan_summary.csv / shopping_mall_summary.csv
      → Gemini 프롬프트에 자동 주입 (CSV 없으면 조용히 생략)

행안부 연령별 인구 API
  → 연령별 인구 수집 (population_age_api.py)
  → 전국 소비층 적합도 산출 (build_national_consumer_fit.py)
      시/도별 연령 분포 비율 × 지역별 인구 → 242개 지역 consumer_fit_score

소상공인 상가정보 API
  → 전국 시군구별 점포수 수집 (store_api.py)
  → 경쟁 포화도 산출 (build_national_competition.py) — 전국 253개 지역, 10개 업종
```

## 주요 지표

| 지표 | 계산 방식 | 의미 |
|---|---|---|
| `opportunity_score` | 공고수(40%) + 금액(25%) + 최근성(15%) + 경쟁도(20%) × 100 | 해당 지역·품목군의 공공수요 종합 매력도 |
| `competition_score` | 품목군 내 공고수 역백분위 = 1 − rank(pct=True) | 신규 진입 용이성 (높을수록 기존 납품사 적음) |
| `recommendation_flag` | 추천 / 제외 / 데이터부족 | 추천 가능 여부 정책 판단 |
| `bids_per_10k_population` | 공고수 ÷ (인구 / 10,000) | 인구 규모 편향을 보정한 수요 밀도 |
| `consumer_fit_score` | 주소비층 연령 비중 min-max 정규화 | 인구 구성 기반 소비층 적합도 (전국 242개 지역) |
| `stores_per_10k` | 점포수 ÷ (인구 / 10,000) | 업종별 경쟁 포화도 (전국 253개 지역, 10개 업종) |
| `hub_score` | 물리적 공고수(50%) + 금액(30%) + 품목다양성(20%) × 100 | 물류 거점 후보 종합 점수 |
| `avg_lead_time_days` | 개찰일 − 공고일 (평균) | 수요 집행 속도 (재고회전 대리 지표) |

## 분류 체계

### 1) `agency_type` (기관 유형, 8종)

| 유형 | 예시 기관 |
|---|---|
| 행정기관 | 서울특별시 강남구, 부산시청 |
| 공공기관/재단 | 강남구도시관리공단, 경기문화재단 |
| 의료기관 | 강남구보건소, OO병원 |
| 어린이집/보육 | 구립어린이집 |
| 학교 | OO초등학교, OO중학교 |
| 복지시설 | OO노인복지관, OO장애인복지원 |
| 문화/체육시설 | OO도서관, OO문화센터 |
| 기타/미분류 | — |

### 2) `item_category_detail` (세부 발주 유형, 18종)

공고명 텍스트 기반 3단계 분류.

1. **키워드 규칙** — `_ITEM_DETAIL_RULES` 순서 매칭 (기존 동작, 해석 가능)
2. **ML 보조** — 미매칭 건에 TF-IDF + Logistic Regression 재분류 (86,991건 훈련, 검증 정확도 98.6%)
3. **fallback** — confidence 미달 시 `기타/미분류` 유지

전국 기준 ML 적용 전 `기타/미분류` **13.1%** → ML 적용 후 **9.2%**.

청소/환경미화, 방역/소독, 폐기물/환경, 급식/식자재, IT장비/전산,  
사무용품/소모품, 시설유지보수, 교육물품/교구, 의료/복지용품,  
행사/운영용역, 조경/녹지관리, 급수/전기/설비, 차량/운송,  
경비/보안, 인쇄/홍보물, 건설/공사, 보험/금융, 전문용역/컨설팅

## 현재 한계

### 1) 데이터부족 비중
지역·품목 조합 중 공고 10건 미만 구간이 상당수 존재합니다.  
이는 보수적 추천 정책의 결과입니다. 임계값을 낮추면 추천 수는 늘지만 신뢰도가 낮아집니다.  
데이터부족 항목에는 AI 판정(블루오션 vs 저수요)을 제공해 활용 가능성을 판단할 수 있도록 했습니다.

### 2) 지역별 공고 건수 편차
경기도(10,714건)·강원(10,437건) 대비 세종(1,469건)·충북(1,533건)은 건수가 적습니다.  
기관 수와 발주 빈도에서 비롯된 구조적 차이이며, `bids_per_10k_population`으로 일부 완화됩니다.

### 3) 공공수요만 반영
민간 소비수요·상권 흐름은 반영하지 않습니다.  
B2G(공공납품) 관점의 분석이며, B2C 업종에는 상권 데이터가 더 적합합니다.

### 4) Gemini 모델
현재 사용 모델: `gemini-3.1-flash-lite` (정식 버전).  
API 실패 시 수치 기반 폴백 문장으로 자동 대체되며 앱은 정상 작동합니다.

## 프로젝트 구조

```text
data/
  raw/                  API 원천 데이터
  processed/            정제 + 분류된 공고 데이터 (전국)
  reference/            인구 레퍼런스 (전국 시·군·구)
outputs/
  tables/               분석 결과 CSV (opportunity_matrix, feature_table 등)
  figures/              히트맵, 분포 그래프
  reports/              요약 리포트
src/
  config/               환경변수·경로·지역 설정
  api/                  공공데이터 API 호출 (조달청, 행안부, 소상공인)

  preprocess/           정제 + 기관/공고명 분류기 (키워드 규칙 + ML fallback)
  modeling/             ML 분류기 훈련·추론 (TF-IDF + LogisticRegression)
  features/             기회 매트릭스, 소비층 적합도, 경쟁 포화도, 인구 보정
  recommendation/       추천 정책, Gemini AI 판정 (4종)
  visualization/        히트맵 생성
  utils/                파일 저장, 로깅
models/
  item_classifier.pkl   공고명 분류 ML 모델 (86,991건 훈련)
streamlit_review.py     메인 대시보드 (10개 탭)
check.md                분류·추천 검수 기록
```

### 타겟 고객

| 고객 | 유형 | 제공 가치 |
|---|---|---|
| 창업지원센터 / 소상공인진흥공단 | B2B | 상담사용 지역별 공공수요 리포트 대시보드 |
| 예비창업자 | B2C | 공공수요 기반 업종·입지 탐색 + AI 진입 판정 |
| B2G 납품업체 | B2B | 지역별 수요 패턴 분석, 영업 거점 우선순위 설정 |
| 물류사 / 3PL | B2B | 공공수요 흐름 기반 물류 거점 최적화 근거 |

### 수익 구조 (단계별)

| 단계 | 형태 | 내용 |
|---|---|---|
| Phase 1 (현재) | 무료 데모 + POC | 라이브 데모 배포, 기관 시범 운영 |
| Phase 2 | B2B 구독형 SaaS | 창업지원기관·납품업체 대상 지역별 리포트 월정액 |
| Phase 3 | 플랫폼 연계 | 조달청 공식 데이터 서비스 + 물류 거점 최적화 컨설팅 |

### 기존 상권분석 서비스와의 차이

| 구분 | 기존 상권분석 | 이 서비스 |
|---|---|---|
| 수요 데이터 | 민간 소비 (카드사·유동인구 추정) | **공공조달 입찰 실계약 이력** |
| 커버 범위 | 민간 B2C 시장 | B2G(공공납품) + 물류 거점 설계 |
| 주요 고객 | 임대업자·프랜차이즈 | 예비창업자·납품업체·물류사 |
| 추천 근거 | 매출·유동인구 추정값 | 조달청 실발주 데이터 정량화 점수 |

## 메모

`opportunity_score`는 **창업 성공 점수**가 아니라 **공공수요 참고 점수**입니다.

AI 판정은 제공된 수치 데이터를 기반으로 한 해석이며,  
창업 성공·투자 수익을 예측하거나 보장하지 않습니다.

이 프로젝트의 목적은 정답을 단정하는 것이 아니라,  
예비창업자·납품업체·물류사가 지역과 품목을 탐색할 때  
**근거 있는 출발점**을 제공하는 것입니다.
